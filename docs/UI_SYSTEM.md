# WorkHub UI System

## Visual direction
Approved direction: warm ivory, white surfaces, orange accent, restrained shadows, premium minimalism.

## Tokens
- Primary: #FF8A00
- Secondary: #FFE4CC
- Background: #FFFAF5
- Surface: #FFFFFF
- Text: #1F2937
- Secondary text: #64748B
- Success: #16A34A
- Warning: #EFA526
- Danger: #DC4444
- Typography: Inter

## Principles
- Avoid generic crowded admin templates.
- Use generous whitespace and clear hierarchy.
- Use restrained orange for primary actions and highlights.
- Use consistent table, filter, form, modal, and navigation patterns.
- Build responsive layouts for desktop, tablet, and mobile.
- Include loading, empty, error, disabled, and success states.
- Ensure keyboard navigation and accessible contrast.
- Use role-aware navigation but never rely on UI hiding for security.

## Shared shell
- Top bar: brand, global search, command palette, notifications, profile.
- Sidebar: workspace, communication, organization, management, settings.
- Content area: page title, contextual actions, filters, content.
