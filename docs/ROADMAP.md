# WorkHub Development Roadmap

## Phase 0 — Foundation
Monorepo, tooling, Docker, database connectivity, API/web/mobile skeleton, CI, docs.

## Phase 1 — Identity and organization
Authentication, employees, departments, teams, reporting hierarchy, roles, permissions, audit.

## Phase 2 — Attendance and timesheets
Clock-in/out, GPS event capture, breaks, shifts, policies, corrections, daily timesheets, manager approval.

## Phase 3 — Projects and tasks
Projects, memberships, tasks, subtasks, dependencies, comments, time logs, views.

## Phase 4 — Dashboards and notifications
Employee, manager, department head, admin dashboards; notifications; reporting.

## Phase 5 — Internal chat
Direct messages, groups, channels, threads, files, search, real-time delivery.

## Phase 6 — WorkHub Mail
Provider connections, mailbox sync, send, inbox, folders, drafts, attachments, email-to-task.

## Phase 7 — Calendar, meetings, documents
Events, invitations, managed video integration, notes, action items, file libraries and versions.

## Phase 8 — HRMS and approvals
Onboarding, leave, employee documents, reusable approvals, payroll after compliance validation.

## Phase 9 — Automation and AI
Rules, triggers, conditions, actions, authorized search, summaries, confirmed write actions.

## Release gates
Every phase requires:
- working end-to-end workflow;
- permission tests;
- unit and integration tests;
- migration review;
- security review appropriate to data sensitivity;
- documentation update;
- staging verification.
